# 🎓 Student Performance Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict whether a student is likely to **Pass or Fail** based on their academic performance and study-related factors.

The project uses a **Random Forest Classifier** to make predictions.

The model considers:

- Study Hours
- Attendance
- Assignment Score
- Previous Exam Score

This project was developed using Python and Google Colab.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand the basics of Machine Learning
- Prepare and analyze a dataset
- Visualize student performance data
- Train a Machine Learning classification model
- Evaluate the model's performance
- Predict the result of a new student

## 📊 Dataset

The dataset contains student academic information.

| Feature | Description |
|---|---|
| Study_Hours | Number of hours spent studying |
| Attendance | Student attendance percentage |
| Assignment_Score | Assignment marks |
| Previous_Exam_Score | Previous examination score |
| Result | Pass or Fail |

The dataset contains 30 student records and is created directly in the notebook for educational purposes.
